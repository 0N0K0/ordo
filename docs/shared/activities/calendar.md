# Paquet partagé : `calendar`

Schémas des événements, agendas et catégories d'agenda, calcul de disponibilité (événements qui occupent quelqu'un), créneaux planifiés (horaires de travail et autres types de créneaux) et condition de créneaux des tâches et routines. Source : `packages/shared/src/calendar/`.

Voir aussi : [Règles : calendrier](../../business-rules/activities/calendar.md), [Dates](../../business-rules/cross-cutting/dates.md), [dates](../cross-cutting/dates.md) (répétitions), [Personnes](../../business-rules/cross-cutting/people.md).

## `calendar.ts` — événements, agendas, catégories

| Export                                                      | Rôle                                                                                                                                          |
| ----------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `calendarEventInputSchema` / `CalendarEventInput`           | Champs d'un événement (tableau ci-dessous). Les heures sont des heures de Paris (décision D7) ; un événement « journée entière » n'en a pas. |
| `EVENT_SCOPES` / `EventScope`                               | Portée d'une modification d'un événement répété : `THIS` (cette occurrence), `FOLLOWING` (celle-ci et les suivantes), `ALL` (toute la série). |
| `calendarCategoryFormSchema` / `CalendarCategoryFormValues` | Catégorie d'agenda : `label` (requis, 250), `color` (requise), `parentId` (catégories en arbre).                                              |
| `calendarFormSchema` / `CalendarFormValues`                 | Agenda de l'espace (chaque événement appartient à un agenda) : `label` (requis, 250), `color`.                                                |
| `occurrenceKey(id, date?)`                                  | Clé d'une occurrence d'un élément répété (événement, routine) un jour : « id\|date » (date vide si aucune). Identique API / web.              |
| `readOccurrenceKey(key)`                                    | Inverse : `{ id, date \| null }`.                                                                                                             |

Champs de `calendarEventInputSchema` :

| Champ                                                       | Règle                                                                                                                                                           |
| ----------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `label`                                                     | Requis, 250 max.                                                                                                                                                |
| `description`                                               | Markdown, 65 536 max (« Texte trop long. »), blanc devient `null`.                                                                                              |
| `location`                                                  | Texte, 250 max, vide devient `null`.                                                                                                                            |
| `links`                                                     | `itemLinksSchema` (voir [core](../cross-cutting/core.md)) : 20 au plus (« 20 liens maximum. ») ; chacun `url` http(s) (« Lien invalide (http ou https). ») et `label` (250 max).                                            |
| `allDay`                                                    | Journée entière.                                                                                                                                                |
| `startDate`, `endDate`                                      | Requis (« La date de début est requise. », « La date de fin est requise. »).                                                                                    |
| `startTime`, `endTime`                                      | `HH:MM` ; requis si l'événement n'est pas « journée entière » (« L’heure de début est requise. », « L’heure de fin est requise. »).                             |
| `recurrence`                                                | Règle de répétition (voir [dates](../cross-cutting/dates.md)) ; sa fin doit suivre le début de l'événement (« La fin de la répétition doit suivre le début. »). |
| `reminders`                                                 | Minutes avant le début, 0 à 43 200 (30 jours), 10 au plus.                                                                                                      |
| `locationLat`, `locationLon`, `travelBefore`, `travelAfter` | `locatedFields` (voir [core](../cross-cutting/core.md)) : point du lieu et temps de trajet aller / retour.                                                      |
| `projectId`                                                 | Projet facultatif.                                                                                                                                              |
| `calendarId`                                                | Agenda ; absent : le premier agenda de l'espace.                                                                                                                |
| `contributorIds`                                            | Contributeurs qui participent (200 max).                                                                                                                        |
| `relationIds`                                               | Relations sans contributeur qui participent (200 max).                                                                                                          |
| `beneficiaryIds`, `beneficiaryRelationIds`                  | « Bénéficiaires » : pour qui est l'événement (200 max chacun).                                                                                                  |
| `categoryIds`                                               | Catégories (50 max).                                                                                                                                            |
| `taskIds`                                                   | Tâches dont parle l'événement (« 50 tâches maximum. »).                                                                                                         |
| `routineLinks`                                              | Routines d'un jour de l'événement (`{ routineId, date }`, ce jour seulement même pour une routine répétée), 200 max.                                            |

La fin (jour + heure, ou jour seul en journée entière) doit suivre le début : « La fin doit suivre le début. » sur `endDate`.


## `event-busy.ts` — occupation par les événements

Sert à savoir si une tâche ou une routine peut être faite à un moment (planification, alarmes, accueil).

| Export                                       | Rôle                                                                                                                                                                                                                                                                                                                                                    |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `BusyEvent`                                  | Occurrence d'événement vue sous l'angle de l'occupation : `label`, `allDay`, `startDate` / `endDate` (inclus), `start` / `end` (instants), `contributorIds` (aucun : « Moi »), `taskIds`, `routineLinks?`, `calledOff` (annulé).                                                                                                                        |
| `blockingEvent(events, item, meId, at, day)` | Événement qui empêche de faire une tâche ou une routine à un moment : non annulé, en cours à ce moment (toute la journée pour un événement journée entière), avec au moins un participant commun (un événement sans participant et un élément sans assigné valent « Moi », `meId`), et qui ne porte ni sur cette tâche ni sur cette routine ce jour-là. |
| `busyUntil(event)`                           | Fin de l'occupation : la fin de l'événement, ou minuit local après son dernier jour s'il dure toute la journée.                                                                                                                                                                                                                                         |
| `sharePeople(assigneeIds, contributorIds)`   | Une tâche peut être rattachée à un événement si ses assignés et les participants ont quelqu'un en commun, ou si l'un des deux côtés est vide.                                                                                                                                                                                                           |

Internes : `BusyItem` (`assigneeIds`, `taskId?`, `routineId?`), `peopleOf` (liste, ou « Moi » si vide).

## `slot-conditions.ts` — condition de créneaux d'une tâche ou d'une routine

La même condition pour les tâches et les routines (décision D9) : un arbre de filtre (groupes « et » / « ou », voir [tables](../cross-cutting/tables.md)) sur trois champs, qui cite des créneaux par leur id ou des types de créneaux par leur référence (`slot-kinds.ts`), de l'espace ou d'un autre espace de l'utilisateur (décision DX). Sans condition : n'importe quand (décision D10). Déplacé de `routines/routine-times.ts`.

| Export                                 | Rôle                                                                                                                                                                                                                  |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SLOT_CONDITION_FIELDS`                | `schedules` (des horaires précis), `kinds` (tous les horaires de certains types, y compris ceux créés plus tard) et `freeTime` (temps libre : hors de tout horaire de l'espace, y compris ceux créés plus tard), tous de type `reference`. |
| `SlotConditionField`                   | `schedules`, `kinds` ou `freeTime`.                                                                                                                                                                                   |
| `SLOT_CONDITION_FIELD_OPERATORS`       | `schedules` et `kinds` : `in` (sur un de ces créneaux / un de ces types), `notIn` (hors de tous) ; `freeTime` : `isEmpty` (hors de tout horaire), `notIn` (hors de tout horaire sauf ceux nommés). Autre opérateur : « Sur ou hors des créneaux. ». |
| `ALL_SCHEDULES`                        | `'*'` : tous les horaires de l'espace, pour demander les créneaux d'un jour.                                                                                                                                            |
| `SlotConditionItem`, `SlotCondition`   | Condition, groupe.                                                                                                                                                                                                    |
| `slotConditionSchema`                  | Schéma d'un groupe de conditions.                                                                                                                                                                                     |
| `readSlotCondition(value)`             | Condition stockée validée, `null` sinon.                                                                                                                                                                              |
| `conditionScheduleIds(node)`           | Horaires cités par une condition (`schedules` et exceptions du temps libre).                                                                                                                                          |
| `conditionKinds(node)`                 | Types cités par une condition (`kinds`).                                                                                                                                                                              |
| `conditionReferences(node)`            | Tout ce qu'une condition cite : horaires et types (ids distincts ; colonne « Créneaux » des tableaux, archivés gardés).                                                                                                |
| `conditionConstrains(node)`            | Vrai si la condition limite les heures (temps libre ou au moins un horaire ou un type cité).                                                                                                                          |
| `TimeWindow`                           | Fenêtre `{ fromTime, dueTime }` (`null` : début ou fin de journée).                                                                                                                                                   |
| `ScheduleQuery`                        | Horaires demandés : `ids` (`ALL_SCHEDULES` : tous ceux de l'espace) et `kinds`.                                                                                                                                       |
| `SlotsOf`                              | Créneaux d'une `ScheduleQuery` un jour donné.                                                                                                                                                                           |
| `conditionWindows(condition, slotsOf)` | Fenêtres permises un jour : `in` = horaires fusionnés (des horaires ou des types cités), `notIn` = hors de ces horaires, temps libre = hors de tous ceux de l'espace ; groupes « et » (intersection) / « ou » (union) ; `null` si rien ne contraint. |
| `windowsAllowed(window, allowed)`      | Parties d'une fenêtre permises par la condition (la fenêtre entière si aucune contrainte ; vide : pas faisable ce jour).                                                                                              |
| `SlotsOn`                              | Créneaux d'une `ScheduleQuery` un jour.                                                                                                                                                                                 |
| `ForeignScheduleRule`                  | Horaire d'un autre espace de l'utilisateur avec son espace (`workspaceId`, `rule`).                                                                                                                                   |
| `scheduleSlotsOn(rules, foreign?)`     | `SlotsOn` des horaires de l'espace et de ceux des autres espaces (comptés seulement là où une condition les cite, eux ou leur type ; jamais dans le temps libre), les horaires de chaque jour calculés à la première demande (API : `loadSlotsOn`, web : `useSlotRules`). |
| `conditionAllowsAt(condition, slotsOn, date, time)` | Un moment est permis par la condition (toujours sans condition).                                                                                                                                          |
| `nextConditionMoment(condition, slotsOn, date, time, days)` | Premier moment permis à partir d'un moment, sur `days` jours (le moment même sans condition) ; `null` si aucun.                                                                                   |

Internes : `Interval`, `intervalOf`, `windowOf`, `merged` (fusion des horaires ; un horaire jusqu'à 23:59 va jusqu'à la fin du jour), `windowsOutside`, `WHOLE_DAY`, `intersect`, `unite`, `conditionIntervals`, `conditionValues`, `slotConditionItemSchema`.

## `slot-kinds.ts` — références des types de créneaux

| Export                                     | Rôle                                                                                                                              |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| `DEFAULT_SLOT_KIND`                        | `'default'` : les créneaux sans type d'un espace (heures de travail, « Travail »).                                                  |
| `ownSlotKind(typeId)`                      | Un type de l'espace : son id, ou `default` sans type.                                                                             |
| `foreignSlotKind(workspaceId, typeId)`     | `ws:<workspaceId>:<typeId \| default>` : un type d'un autre espace (clé des abonnements aux types de créneaux, et des conditions). |
| `foreignSlotKindWorkspace(kind)`           | Espace d'une référence `ws:…` ; `null` pour un type de l'espace.                                                                  |
| `scheduleSlotKind(schedule, workspaceId?)` | Type d'un horaire tel qu'une condition le cite (`ownSlotKind`, ou `foreignSlotKind` pour un horaire d'un autre espace).           |

La règle par types de créneaux (`slotRuleSchema`, `readSlotRule`, `effectiveSlotRule`, `allowedAt`, `nextAllowed`, `knownSlotRule`, `kindedSlots`, `scheduleKinds`) est supprimée : les tâches prennent la condition des routines (décision D9), qui cite aussi les types (décision DX).

## `work-schedules.ts` — créneaux planifiés (horaires)

Un horaire (« créneau » dans l'interface) a un libellé, un type (aucun : heures de travail), une période, des cas (répétition + horaires) et des exceptions (périodes avec leurs propres cas ; sans cas : une pause, des congés).

| Export                                                        | Rôle                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SchedulePattern`                                             | Ancienne forme d'un cas : `DAILY`, `WEEKLY`, `EVERY_N_DAYS`, `MONTHLY`, `YEARLY`.                                                                                                                                                                                                                                                                                                                                                                         |
| `ScheduleTimes`                                               | Horaires d'un cas : `allDay` ou `ranges` (`{ start, end }`, fin strictement après début, 12 tranches max : « 12 tranches au plus. »).                                                                                                                                                                                                                                                                                                                     |
| `ScheduleCase`                                                | `RepetitionCase<ScheduleTimes>`.                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `ScheduleException`                                           | Exception : `from`, `to` (fin après début), `label` (250 max), `cases` (20 max ; vide : pause).                                                                                                                                                                                                                                                                                                                                                           |
| `workScheduleSchema` / `WorkScheduleInput`                    | Horaire : `label` (requis, 250), `startDate`, `endDate` (facultative, après le début), `cases` (1 à 20 : « Ajoutez au moins un cas. », « 20 cas au plus. »), `exceptions` (200 max : « 200 exceptions au plus. »), `typeId` (type de créneau ; aucun : heures de travail).                                                                                                                                                                                  |
| `WorkScheduleRule`                                            | Horaire stocké tel que lu par les fonctions : `id`, `label`, `startDate`, `endDate`, `cases`, `exceptions`, `typeId?`.                                                                                                                                                                                                                                                                                                                                    |
| `PlannedSlot`                                                 | Créneau un jour : `date`, `start`, `end`, `allDay` (« 00:00 » à « 24:00 »), `scheduleId`.                                                                                                                                                                                                                                                                                                                                                                   |
| `weekdayOf(date)`                                             | Jour ISO (1 à 7).                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `isoWeekYear(date)`                                           | Année d'une semaine ISO (celle de son jeudi).                                                                                                                                                                                                                                                                                                                                                                                                             |
| `plannedSlots(schedules, from, to)`                           | Créneaux du jour planifiés entre deux dates (incluses), triés par date puis début. Un jour couvert par une exception utilise les cas de l'exception (celle commencée le plus tard, puis la plus courte), sinon les cas généraux ; rien après `endDate`.                                                                                                                                                                                                           |
| `plannedPauses(schedules, from, to)`                          | Pauses (exceptions sans cas) qui chevauchent la période, avec le libellé de l'horaire.                                                                                                                                                                                                                                                                                                                                                                    |
| `slotMinutes(slots)`                                          | Minutes de créneaux (les journées entières ne comptent pas comme temps de travail prévu).                                                                                                                                                                                                                                                                                                                                                                   |
| `withinSlots(slots, date, start, end)`                        | Une tranche horaire tient dans un créneau du jour.                                                                                                                                                                                                                                                                                                                                                                                                         |
| `readScheduleCases(value, periodStart)`                       | Cas stockés (JSON) validés, invalides écartés, ancienne forme convertie.                                                                                                                                                                                                                                                                                                                                                                                  |
| `readScheduleExceptions(value)`                               | Exceptions stockées validées (fin avant début écartée), cas convertis.                                                                                                                                                                                                                                                                                                                                                                                    |
| `fromLegacySchedule(legacy)`                                  | Convertit l'ancien format (`startDate`, `intervalWeeks`, `slots` par jour de semaine, `pauses`) : les jours aux mêmes horaires deviennent un cas hebdomadaire, les pauses des exceptions sans cas.                                                                                                                                                                                                                                                        |
| `ScheduleDayDisplay`                                          | Affichage en vue semaine / jour : `SLOT_BACKGROUND` (heures en fond), `DAY_BACKGROUND` (journée en fond), `SLOT_BORDER` (fin trait à gauche), `NONE`.                                                                                                                                                                                                                                                                                                     |
| `ScheduleMonthDisplay`                                        | Affichage en vue mois : `BACKGROUND`, `BORDER` (trait en bas), `NONE`.                                                                                                                                                                                                                                                                                                                                                                                    |
| `ScheduleDisplay`                                             | `{ dayDisplay, dayBar (barre en haut des jours avec créneaux), monthDisplay }`.                                                                                                                                                                                                                                                                                                                                                                             |
| `DEFAULT_SCHEDULE_DISPLAY`                                    | `SLOT_BACKGROUND`, barre affichée, `BACKGROUND`.                                                                                                                                                                                                                                                                                                                                                                                                          |
| `scheduleTypeSchema` / `ScheduleTypeInput`                    | Type de créneaux (« Travail », « Garde des enfants »…) : `label` (requis, 250), `color`, affichage.                                                                                                                                                                                                                                                                                                                                                         |
| `DEFAULT_SCHEDULE_KIND_LABEL`                                 | « Travail » : libellé des créneaux sans type si l'espace ne le renomme pas.                                                                                                                                                                                                                                                                                                                                                                                 |
| `defaultScheduleKindSchema` / `DefaultScheduleKindInput`      | Réglage des créneaux sans type de l'espace : `label` (250 max, vide : « Travail »), `color` (aucune : le vert des heures de travail), affichage.                                                                                                                                                                                                                                                                                                            |
| `scheduleSubscriptionLookSchema` / `ScheduleSubscriptionLook` | Couleur et affichage d'un type de créneaux d'un autre espace dans l'espace abonné ; `null` : ceux du type.                                                                                                                                                                                                                                                                                                                                                  |
| `readScheduleDisplay(value)`                                  | Affichage depuis des valeurs stockées, inconnues remplacées par le défaut.                                                                                                                                                                                                                                                                                                                                                                                |
| `ScheduleSlotTime`                                            | Créneau d'un jour déplacé ou étiré dans le calendrier : `date`, `start`, `end`, `allDay`.                                                                                                                                                                                                                                                                                                                                                                           |
| `changedScheduleSlot(schedule, slot, change, scope)`          | Nouveaux cas et exceptions après déplacement, étirement ou suppression (`change = null`) d'un créneau depuis le calendrier. `THIS` : exception du jour (et du jour d'arrivée) avec ses propres horaires ; `FOLLOWING` : le cas s'arrête la veille et un nouveau cas suit avec la modification (coupure seulement si le cas avait des jours avant) ; `ALL` : tous les jours du cas. Le rythme suit le créneau (nouveau jour de semaine, nouveau jour du mois…). |

Erreurs de `changedScheduleSlot` (levées en `Error`) : « La fin doit suivre le début. », « Ce jour est en dehors de la période du créneau. », « Horaires introuvables ce jour-là. », « Ce sont les derniers horaires du créneau : supprimez le créneau lui-même. ».

Erreurs de validation des cas : « Ajoutez des horaires, ou « Journée entière ». », « Des horaires se chevauchent. », « Choisissez au moins un jour. » (hebdomadaire sans jour), « Semaine ou mois : chaque année seulement. » (ancienne forme), « Au moins 1 jour. », « 366 jours au plus. ».

Internes : `timeRangeSchema`, `refineScheduleTimes`, `scheduleCaseSchema` (ancienne forme), `scheduleTimesSchema`, `scheduleRepetitionCaseSchema`, `exceptionFields`, `scheduleExceptionSchema`, `PlannedPause`, `mondayOf`, `caseAnchor`, `scheduleCaseRepetition` (conversion ancienne forme → répétition commune), `caseOn`, `casesOn`, `legacySlotSchema`, `legacyPauseSchema`, `singleSlotCase`, `withDaySlots`, `daySlots`, `sameHours`, `movedCase`.
