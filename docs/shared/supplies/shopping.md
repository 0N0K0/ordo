# Paquet partagé : `shopping`

Schémas et calculs des courses (catégories, magasins, listes types et produits, listes de courses, commandes et livraisons), des fiches (recettes, check-lists) et du stock (articles, lots, mouvements, inventaires). Source : `packages/shared/src/shopping/`.

Voir aussi : [Règles : courses](../../business-rules/supplies/shopping.md), [Règles : stock](../../business-rules/supplies/stock.md), [Règles : fiches](../../business-rules/supplies/sheets.md).

## `shopping.ts` — produits et listes de courses

| Export                                                | Rôle                                                                                                                                                                                                                                                              |
| ----------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `UNIT_MAX`                                            | `50` : longueur d'une unité (fiche, stock, course), comme une unité des réglages.                                                                                                                                                                                 |
| `ITEM_NOTE_MAX`                                       | `500` : longueur de la note d'un produit.                                                                                                                                                                                                                         |
| `SHOPPING_LABEL_MAX`                                  | `120` : libellé d'un produit ou d'un article de course.                                                                                                                                                                                                           |
| `quantitySchema`                                      | Quantité : nombre (« Nombre attendu. »), ≥ 0 (« Quantité positive attendue. »), ≤ 999 999 (« Quantité trop grande. »).                                                                                                                                            |
| `unitSchema`                                          | Unité facultative (vide : `null`).                                                                                                                                                                                                                                |
| `itemNoteSchema`                                      | Note markdown facultative, 500 max.                                                                                                                                                                                                                               |
| `ShoppingStoreInput`                                  | Magasin, mode de conservation ou unité : `LabelFormValues` (libellé + couleur, voir [core](../cross-cutting/core.md)).                                                                                                                                            |
| `shoppingCategorySchema` / `ShoppingCategoryInput`    | Catégorie de produits (arbre) : `label` (requis, 100), `color`, `parentId`, `baseListIds` (listes types où elle est proposée ; aucune : toutes ; une sous-catégorie sans liste prend celles de son parent ; 100 max).                                             |
| `shoppingProductSchema` / `ShoppingProductInput`      | Produit d'une liste type : champs communs + `baseListId` (« La liste type est requise. ») + `missing` (manquant).                                                                                                                                                 |
| `shoppingItemSchema` / `ShoppingItemInput`            | Article d'une liste : champs communs + `optional` (acheté si possible ; la liste est terminée sans lui).                                                                                                                                                          |
| `shoppingBaseListLabelSchema`                         | Libellé d'une liste type : requis, 80.                                                                                                                                                                                                                            |
| `SHOPPING_LIST_LABEL_MAX` / `shoppingListLabelSchema` | Libellé d'une liste de courses : requis, 120.                                                                                                                                                                                                                     |
| `shoppingListFormSchema`                              | Formulaire d'une liste : `label`, `taskIds` (tâches liées).                                                                                                                                                                                                       |
| `shoppingCost(item)`                                  | Coût estimé : quantité (1 si aucune) × prix unitaire, arrondi au centime ; `null` sans prix.                                                                                                                                                                      |
| `shoppingShares(items)`                               | Part de chaque membre et relation dans le coût des articles, en centimes : un article pour plusieurs personnes est partagé également (les centimes restants vont aux premières personnes) ; un article pour personne n'est pas réparti mais compte dans le total. |
| `DEFAULT_SHOPPING_UNITS`                              | Unités d'un nouvel espace : « pièce », « kg », « g », « L », « cl », « boîte », « paquet », « bouteille », « sachet », « lot », « rouleau », « carton », « paire ».                                                                                               |
| `productKey(item)`                                    | Clé de ce que contient une ligne, identique dans les fiches, les listes et le stock : `p:<productId>`, sinon `l:<nameKey(label)>\|<nameKey(unit)>`. Deux lignes de même clé sont le même produit (additionnées, rangées ensemble).                                |

Champs communs d'un produit et d'un article (`shoppingFields`, interne) : `label` (requis, 120), `categoryId`, `storeId`, `url` (http(s), « Lien invalide (http ou https). »), `note`, `quantity`, `unit`, `unitPrice` (≥ 0 : « Le prix ne peut pas être négatif. », ≤ 9 999 999 : « Prix trop grand. »), `memberIds` / `relationIds` (pour qui, 50 max), `perishable`, `storageId` et `expiresAt` (« à consommer avant », ignorés si non périssable).

Internes : `linkSchema`, `priceSchema`, `shoppingFields`.

## `sheets.ts` — fiches

Une fiche (recette, check-list…) liste des articles ; elle peut être ajoutée à une liste de courses, à une routine, à un événement ou à une tâche avec un multiplicateur.

| Export                                       | Rôle                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `sheetItemSchema` / `SheetItemInput`         | Article d'une fiche : `id` (article conservé, avec ses commentaires), `productId` (produit des listes types) ou libellé propre (`label`, requis, 200), `categoryId`, `quantity`, `unit`, `note`, `consumable` (consommé à l'utilisation, pris du stock ; pour une check-list : pris quand coché ; vrai par défaut), et comme les articles de courses `storeId`, `url`, `perishable`, `storageId`, `memberIds`, `relationIds`, `optional`. |
| `SHEET_LABEL_MAX`                            | `100`.                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `sheetSchema` / `SheetInput`                 | Fiche : `label` (requis, 100), `note` (20 000, « Note trop longue. »), `projectId` (aucun : fiche de l'espace), `categoryIds` (50 max). Ses articles se modifient un par un.                                                                                                                                                                                                                                                              |
| `sheetCategorySchema` / `SheetCategoryInput` | Catégorie de fiches : `label` (requis, 60), `color`.                                                                                                                                                                                                                                                                                                                                                                                      |
| `sheetMultiplierSchema`                      | Multiplicateur (2 × « Crêpes ») : > 0 (« Multiplicateur positif attendu. »), ≤ 999 (« 999 au plus. »).                                                                                                                                                                                                                                                                                                                                    |
| `sheetLinkSchema` / `SheetLinkInput`         | Fiche d'une routine, d'un événement ou d'une tâche : `sheetId`, `multiplier`.                                                                                                                                                                                                                                                                                                                                                             |
| `checklistItemSchema`                        | Article de check-list ajouté ou modifié à la main (même schéma que `sheetItemSchema`).                                                                                                                                                                                                                                                                                                                                                    |
| `SheetSource`                                | Part d'une fiche dans un article de liste : `sheetId`, `label` (au moment de l'ajout), `quantity` apportée.                                                                                                                                                                                                                                                                                                                               |
| `readSheetSources(value)`                    | Sources stockées (JSON) validées ; invalides : liste vide.                                                                                                                                                                                                                                                                                                                                                                                |
| `roundQuantity(value)`                       | Arrondi au millième (précision des quantités stockées).                                                                                                                                                                                                                                                                                                                                                                                   |
| `addQuantities(a, b)`                        | Somme de deux quantités dont une peut manquer ; `null` si les deux manquent.                                                                                                                                                                                                                                                                                                                                                              |
| `timesSheet(value, multiplier)`              | Quantité × multiplicateur, arrondie.                                                                                                                                                                                                                                                                                                                                                                                                      |

## `stock.ts` — stock, commandes, livraisons

| Export                                             | Rôle                                                                                                                                                                                                                                                                                                                             |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `stockLocationSchema` / `StockLocationInput`       | Emplacement (Frigo, Congélateur…, arbre) : `label` (requis, 80), `color`, `parentId`.                                                                                                                                                                                                                                            |
| `stockItemSchema` / `StockItemInput`               | Article du stock : `productId` (référence suivie) ou article propre, `label` (requis, 200), `categoryId`, `unit`, `locationId`, `note`, `perishable`, `memberIds`, `relationIds` (100 max).                                                                                                                                      |
| `newStockItemSchema` / `NewStockItemInput`         | Nouvel article avec un premier lot : + `quantity`, `expiresAt`.                                                                                                                                                                                                                                                                  |
| `STOCK_MOVEMENT_KINDS` / `StockMovementKind`       | `PURCHASE`, `CONSUMPTION`, `COUNT`, `LOSS`, `CORRECTION`.                                                                                                                                                                                                                                                                        |
| `STOCK_MOVEMENT_LABELS`                            | « Achat », « Consommation », « Inventaire », « Perte », « Correction ».                                                                                                                                                                                                                                                          |
| `stockMoveSchema` / `StockMoveInput`               | Mouvement manuel : `itemId`, `kind` (sauf `COUNT`), `quantity` (non nulle : « Quantité non nulle attendue. » ; positive sauf correction : « Quantité positive attendue. »), `lotId` (lot pris ; aucun : ceux qui expirent en premier ; ou lot complété ; aucun : nouveau lot), `expiresAt` (date du nouveau lot), `note` (2000). |
| `stockCountSchema` / `StockCountInput`             | Inventaire : `locationId` (un emplacement ou tout), `note`, `lines` (`itemId`, `counted` ; 1 à 2000 : « Comptez au moins un article. »).                                                                                                                                                                                         |
| `productStockSchema` / `ProductStockInput`         | Réglages de stock d'une référence : `stockTracked`, `consumable`, `autoStock`, `stockLocationId`.                                                                                                                                                                                                                                |
| `stockPurchaseSchema` / `StockPurchaseInput`       | Achat mis en stock depuis une liste : `shoppingItemId`, `quantity` > 0, `locationId`, `expiresAt`.                                                                                                                                                                                                                               |
| `shoppingOrderSchema` / `ShoppingOrderInput`       | Commande à distance d'une liste : `remote`, `deliveryAddress` (500), `deliveryLat`, `deliveryLon`.                                                                                                                                                                                                                               |
| `shoppingDeliverySchema` / `ShoppingDeliveryInput` | Livraison : `label` (120), `trackingUrl` (http(s)), `pickup` (retrait plutôt que livraison), `windowFrom` / `windowTo` (fin après début), `address`, `lat`, `lon` (lieu autre que celui de la commande), `itemIds` (articles apportés, 500 max).                                                                                 |

Internes : `url`.
