# Paquet partagé : `tables`

Filtres, vues enregistrées, mise en page des colonnes et totaux des tableaux (le `DataTable` unique du web et ses vues stockées par l'API). Source : `packages/shared/src/tables/`.

Voir aussi : [Composants web : data-table](../../web/components/data-table.md), [Composants web : filters](../../web/components/filters.md), [Dates](../../business-rules/cross-cutting/dates.md).

## `filters.ts` — arbre de filtres

Un filtre est un arbre : un groupe racine (`and` / `or`) contenant des conditions et des sous-groupes. Les types de champ décident des opérateurs.

| Export                                      | Rôle                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `FilterFieldKind`                           | `text`, `number`, `date`, `reference`, `multiReference`, `sprint`, `boolean`, `category`.                                                                                                                                                                                                                                                                                                                                                    |
| `FILTER_OPERATORS`                          | Opérateurs par type (tableau ci-dessous).                                                                                                                                                                                                                                                                                                                                                                                                    |
| `FilterOperator`                            | Union de tous les opérateurs.                                                                                                                                                                                                                                                                                                                                                                                                                |
| `ME`                                        | `'@me'` : valeur d'une condition « assigné » qui désigne le profil contributeur de l'utilisateur connecté.                                                                                                                                                                                                                                                                                                                                   |
| `VALUELESS_OPERATORS`                       | Opérateurs sans valeur : `isEmpty`, `isNotEmpty`, `isTrue`, `isFalse`, `current`, `previous`, `next`, `past`, `future`.                                                                                                                                                                                                                                                                                                                      |
| `DATE_PERIODS` / `DatePeriod`               | Périodes nommées : `thisWeek`, `lastWeek`, `nextWeek`, `thisMonth`, `lastMonth`, `nextMonth`, `thisQuarter`, `lastQuarter`, `nextQuarter`, `thisYear`, `lastYear`, `nextYear`.                                                                                                                                                                                                                                                               |
| `DATE_PERIOD_LABELS`                        | Leurs noms, identiques partout (filtres, formulaires d'export, tableaux de bord) : « Cette semaine », « La semaine dernière », « La semaine prochaine », « Ce mois-ci », « Le mois dernier », « Le mois prochain », « Ce trimestre », « Le trimestre dernier », « Le trimestre prochain », « Cette année », « L’année dernière », « L’année prochaine ».                                                                                     |
| `filterDay(token, today)`                   | Jour d'un jeton `YYYY-MM-DD`, `today`, `today+3`, `today-7`.                                                                                                                                                                                                                                                                                                                                                                                 |
| `filterDaySchema`                           | Schéma d'un jeton de jour (« Date invalide. ») : la valeur d'une condition de date, et le jour que donne une action d'automatisation des tâches. |
| `filterPeriod(token, today, week?)`         | `[premier jour, lendemain du dernier]` d'une période nommée ou glissante (`past:7` : les 7 derniers jours, aujourd'hui compris ; `next:30` : les 30 prochains, aujourd'hui compris). Les semaines sont celles de l'espace. La fin est exclusive.                                                                                                                                                                                             |
| `FilterConditionOf<F>`                      | Condition `{ type: 'condition', id, field, operator, value? }`.                                                                                                                                                                                                                                                                                                                                                                              |
| `FilterGroupOf<F>`                          | Groupe `{ type: 'group', id, combinator: 'and' \| 'or', children }`.                                                                                                                                                                                                                                                                                                                                                                         |
| `filterConditionSchemaFor(fields, choices)` | Schéma d'une condition pour un jeu de champs typés (tâches, routines…) : l'opérateur doit convenir au type (« Opérateur invalide pour ce champ. ») et la valeur aussi : « Texte attendu. », « Nombre attendu. », « Date invalide. » / « Période invalide. » (pour `within`), « Choisissez au moins une valeur. » (références, sprints), « Choisissez au moins une catégorie. » (valeurs autorisées par `choices` ; `null` : toute valeur, les ids d'une liste connue ailleurs). `id` : 1 à 64 caractères. |
| `filterGroupSchemaFor(condition)`           | Schéma récursif d'un groupe, 50 enfants au plus par groupe.                                                                                                                                                                                                                                                                                                                                                                                  |
| `MAX_FILTER_DEPTH`                          | `5` : profondeur maximale des groupes.                                                                                                                                                                                                                                                                                                                                                                                                       |
| `filterDepth(group)`                        | Profondeur d'un arbre (1 pour un groupe de conditions).                                                                                                                                                                                                                                                                                                                                                                                      |

Opérateurs par type :

| Type             | Opérateurs                                                                                                                                                                                                                          |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `text`           | `contains`, `notContains`, `is`, `isNot`, `isEmpty`, `isNotEmpty`                                                                                                                                                                   |
| `number`         | `eq`, `neq`, `lt`, `lte`, `gt`, `gte`, `isEmpty`, `isNotEmpty`                                                                                                                                                                      |
| `date`           | `is`, `before`, `after`, `onOrBefore`, `onOrAfter`, `within`, `isEmpty`, `isNotEmpty`                                                                                                                                               |
| `reference`      | `in`, `notIn`, `inTree` (l'élément ou un de ses descendants : projet, parent), `isEmpty`, `isNotEmpty`                                                                                                                              |
| `multiReference` | `anyOf`, `allOf`, `noneOf`, `isEmpty`, `isNotEmpty`                                                                                                                                                                                 |
| `sprint`         | `in`, `notIn`, `allOf`, `current`, `previous`, `next`, `past`, `future`, `isEmpty`, `isNotEmpty` (une tâche peut être dans plusieurs sprints ; elle correspond si l'un d'eux correspond ; précédent / suivant par arbre de projets) |
| `boolean`        | `isTrue`, `isFalse`                                                                                                                                                                                                                 |
| `category`       | `in`, `notIn`, `isEmpty`, `isNotEmpty`                                                                                                                                                                                              |

## `filter-match.ts` — application d'un filtre

La règle unique d'un filtre sur une ligne, la même dans l'app (tableaux, tableaux de bord, accueil) et dans l'API (conditions des automatisations des tâches).

| Export                                        | Rôle |
| --------------------------------------------- | ---- |
| `FilterValueKind`, `FilterFieldValue`         | Valeur d'une ligne lue par une condition, avec son type (`text`, `number`, `date`, `boolean`, `choice`, `choices`) et le choix « Aucun » d'une liste (`none`, compté vide). |
| `meetsCondition(condition, value, today, week?)` | Si la valeur remplit une condition complète : vide / non vide, oui / non ; textes sans casse ni accents (`contains`, `notContains`, `is`, `isNot`) ; nombres ; jours (`YYYY-MM-DD`) comparés au jour du jeton (`filterDay`), `within` sur une période (`filterPeriod`, semaines de l'espace) ; un choix (`in`, `notIn`) ; plusieurs (`anyOf` / `in`, `allOf`, `noneOf` / `notIn`). |
| `matchesFilter(group, meets)`                 | Si une ligne remplit un arbre : tous les enfants d'un groupe « et », l'un d'eux d'un groupe « ou » ; un groupe vide est rempli. |

## `table-views.ts` — vues enregistrées

| Export                                      | Rôle                                                                                                                                                                                    |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `VIEW_KINDS`                                | `TASKS`, `ROUTINES`, `SHOPPING_LISTS`, `TABLE` (tout autre tableau, nommé par sa clé).                                                                                                  |
| `tableKeySchema`                            | Clé de tableau : `^[a-z0-9-]{1,64}$` (« Tableau invalide. »), ex. `time-log`, `treasury-entries`.                                                                                       |
| `TableFilterGroup`                          | Filtre d'un tableau (`FilterGroupOf<string>`) : les champs sont les ids de colonnes ; seul le web connaît leur type et ignore les conditions inapplicables.                             |
| `searchTextSchema`                          | Texte cherché dans un tableau ou un graphique, tel que tapé (non rogné) : 250 caractères max (`TEXT_MAX`, « 250 caractères maximum. »), `''` par défaut.                   |
| `tableFilterSchema`                         | Filtre racine : valeur texte 500 max, listes 200 éléments de 200 caractères max (bornes internes des vues) ; profondeur limitée (« Les groupes de filtres sont limités à 5 niveaux. »). |
| `GROUP_PERIODS` / `GroupPeriod`             | Regroupement sur une date : `DAY`, `WEEK`, `MONTH`, `QUARTER`, `YEAR`.                                                                                                                  |
| `tableViewConfigSchema` / `TableViewConfig` | Configuration d'une vue (tableau ci-dessous). Les champs invalides retombent sur leur défaut (`catch`) au lieu de refuser la vue.                                                       |
| `emptyTableFilter()`                        | Groupe racine vide `{ id: 'root', combinator: 'and' }` (toutes les lignes).                                                                                                             |
| `tableViewConfig(config?)`                  | Configuration complète à partir de réglages partiels.                                                                                                                                   |
| `newTableViewConfig(columns, config?)`      | Configuration d'une nouvelle vue : les colonnes de départ du tableau dans l'espace (`TableColumnDefaults`, aucune : celles de l'application), puis ses propres réglages. Lue par les vues créées, les premières vues et « Colonnes par défaut » des options d'une vue. |
| `viewColumnLayout(config)`                  | `ColumnLayout` d'une vue (ordre, colonnes masquées, largeurs), vide sans vue.                                                                                                           |
| `viewLabelSchema`                           | Libellé d'une vue : requis, 250 caractères max.                                                                                                                                         |

Champs de `tableViewConfigSchema` :

| Champ                                          | Défaut      | Rôle                                                                                           |
| ---------------------------------------------- | ----------- | ---------------------------------------------------------------------------------------------- |
| `filter`                                       | groupe vide | Filtre.                                                                                        |
| `search`                                       | `''`        | Recherche (`searchTextSchema`), 250 max.                                                       |
| `sorting`                                      | `[]`        | Tris `{ id, desc }`, 30 max.                                                                   |
| `groupBy`                                      | `null`      | Colonne de regroupement.                                                                       |
| `groupPeriod`                                  | `MONTH`     | Période d'un regroupement sur une date.                                                        |
| `flat`                                         | `false`     | Sous-lignes à plat (tableau en arbre).                                                         |
| `includeArchived`                              | `false`     | Lignes archivées affichées aussi.                                                              |
| `options`                                      | `{}`        | Options propres au tableau (ex. événements listés avec les tâches).                            |
| `columnOrder`, `hiddenColumns`, `columnSizing` | vides       | Mise en page (voir `table-layout.ts`).                                                         |
| `footer`                                       | `null`      | Total par colonne (`count`, `sum`, `avg`, `median`) ; `null` : pas de pied.                    |
| `manualOrder`                                  | `[]`        | Clés des lignes dans l'ordre choisi à la main (utilisé sans tri), 5000 max ; les autres après. |

## `table-layout.ts` — colonnes et compatibilité

| Export                                | Rôle                                                                                                                                                                                                                                                                                                                                  |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `TABLE_KEY_MAX`                       | `64` : longueur d'une clé de tableau (id de colonne, champ, opérateur de filtre) ; une clé, pas un texte libre.                                                                                                                                                                                                                       |
| `columnLayoutSchema` / `ColumnLayout` | `columnOrder` et `hiddenColumns` (100 ids de `TABLE_KEY_MAX` caractères max), `columnSizing` (largeurs 40 à 1200 px). Les ids inconnus sont ignorés.                                                                                                                                                                                  |
| `tableSortSchema` / `TableSort`       | `{ id, desc }`.                                                                                                                                                                                                                                                                                                                       |
| `legacyLabelColumn(tableKey)`         | Ancien id de la colonne libellé (`title` ou `name`) d'un tableau dont les vues peuvent encore le contenir (identifiants renommés `label`) : `tasks`, `routines`, `catalog`, `project-documents`, tous les `documents-*` → `title` ; `recurring-invoices`, `sheets`, `shopping-lists`, `shopping-list`, `shopping-base-list`, `work-schedules` → `name`. |
| `LegacyFilterValues`                  | Anciennes valeurs de filtres de choix par colonne, avec leur nouvelle valeur.                                                                                                                                                                                                                                                         |
| `withFilterValues(stored, values)`    | Vue stockée dont les anciennes valeurs de filtres de choix sont lues comme les nouvelles (les vues stockées ne sont pas réécrites).                                                                                                                                                                                                   |
| `withLabelColumn(stored, from)`       | Vue ou mise en page stockée dont l'ancien id de colonne libellé est lu comme `label` : ordre, colonnes masquées, largeurs, tris, regroupement, pied, filtre.                                                                                                                                                                          |
| `tableColumnDefaultsSchema` / `TableColumnDefaults` | Colonnes de départ des nouvelles vues d'un tableau dans un espace : `columnOrder`, `hiddenColumns` (200 ids de `TABLE_KEY_MAX` caractères max ; `label` ne peut jamais être masqué). |
| `TABLE_COLUMN_DEFAULTS_MAX`           | `200` : nombre de tableaux au plus dont un espace garde les colonnes par défaut.                                                                                                                                                                                                                                                       |
| `readTableColumnDefaults(stored, tableKey)` | Valeur stockée d'un tableau (ancien id de sa colonne libellé lu comme `label`), sinon mise en page vide (celle de l'application).                                                                                                                                                                                                  |
| `storedTableColumnDefaults(stored)`   | Colonnes par défaut de tous les tableaux d'un espace telles que stockées (`Workspace.tableColumns`), par clé de tableau ; toute autre valeur lue comme aucune.                                                                                                                                                                         |

Internes : `LEGACY_LABEL_COLUMNS`, `aliased`, `mapConditions` (applique un changement à chaque condition d'un arbre), `aliasedFilter`, `columnIdsSchema`.

## `aggregates.ts` — totaux de pied de tableau

| Export                                | Rôle                                                                                                            |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `TABLE_AGGREGATES` / `TableAggregate` | `count`, `sum`, `avg`, `median`.                                                                                |
| `aggregateValues(aggregate, values)`  | `count` : nombre de valeurs non vides ; sinon somme, moyenne ou médiane des nombres finis ; `null` sans nombre. |
