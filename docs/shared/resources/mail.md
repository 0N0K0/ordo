# Paquet partagé : `mail`

Schémas des boîtes mail (IMAP / SMTP), signatures, destinataires, recherches et dossiers de recherche, tris. Source : `packages/shared/src/mail/mail.ts`.

Voir aussi : [Fonctionnalités : mail](../../features/resources/mail.md), [Règles : mail](../../business-rules/resources/mail.md).

## `mail.ts`

| Export                                               | Rôle                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ---------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `MAIL_SORTS`                                         | Tris d'un dossier : `date`, `correspondent`, `subject`, `size` (une recherche trie sur tous sauf la taille).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `MailSortBy`, `MailSearchSortBy`                     | Champ de tri d'un dossier, d'une recherche (sans `size`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `mailSortBy(sort)`                                   | Champ de tri depuis une valeur reçue ; inconnu : `date`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `mailSearchSortBy(sort)`                             | Idem pour une recherche ; `size` devient `date`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `mailTime(header, received)`                         | Date d'un mail en millisecondes, celle affichée et celle du tri par date : l'en-tête Date, sinon la date de réception par le serveur (INTERNALDATE) ; 0 sans l'une ni l'autre.                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `dateHeader(headers)`                                | Valeur de l'en-tête Date dans des en-têtes bruts (lignes repliées jointes) ; null sans lui.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `compareMailDates(a, b, ascending?)` / `MailDateKey` | Ordre de deux mails `{ time, uid }` par date : le plus récent d'abord, le plus grand UID d'abord entre égaux ; croissant = l'inverse exact.                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `searchKeepsOldest(sort)`                            | Vrai quand une recherche garde les 200 mails les plus anciens de chaque dossier (tri par date croissant) au lieu des plus récents.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `NO_SUBJECT`                                         | « (sans objet) ».                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `mailAccountFormSchema` / `MailAccountFormValues`    | Boîte : `label` (requis, 250), `email` (« Adresse email invalide. »), `displayName` (250), `imapHost` / `smtpHost` (« Le serveur est requis. », 255), `imapPort` / `smtpPort` (1 à 65 535, « Port attendu. », « Port invalide. »), `imapSecure` / `smtpSecure`, `imapUser` / `smtpUser` (« L’identifiant est requis. »), `imapPassword` / `smtpPassword` (1000 max ; vides en modification : les mots de passe enregistrés sont gardés), `saveSent` (copie dans « Envoyés »).                                                                                                                                         |
| `MailServerSettings`                                 | Serveurs d'une boîte enregistrée (hôtes, ports, identifiants, chiffrement) : ce pour quoi ses mots de passe ont été enregistrés.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `PASSWORD_AGAIN`                                     | « Saisissez à nouveau le mot de passe : le serveur, le port, l’identifiant ou le chiffrement a changé. ».                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `passwordsToRetype(values, saved)`                   | Mots de passe à ressaisir (`imapPassword`, `smtpPassword`) : un côté dont le serveur, le port, l'identifiant ou le chiffrement a changé sans son mot de passe ; aucun pour une nouvelle boîte. Le même dans le panneau d'une boîte (avant d'enregistrer sa connexion) et l'API.                                                                                                                                                                                                                                                                                                                                       |
| `mailFolderNameSchema`                               | Nom d'un dossier du serveur (création, renommage) : `requiredText()` (« Le libellé est requis. », 250 caractères max) sans `*`, `%`, `"` ni `\` (« Caractères interdits : * % " \ ») ; le même pour le web et l'API.                                                                                                                                                                                                                                                                                                                                                                                                  |
| `signatureSchema`                                    | Signature HTML, 100 000 caractères max (« Signature trop longue. ») ; nettoyée par l'API.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `signatureFormSchema`                                | Signature dans son éditeur : `{ signature }` (`signatureSchema`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `recipientsSchema`                                   | Destinataires : adresses email, 100 max (« 100 destinataires maximum. »).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `mailSearchCriteriaSchema` / `MailSearchCriteria`    | Critères : `accountIds` (vide : toutes les boîtes, 50 max), `scope` (`inbox` ; `all` : tous les dossiers sauf corbeille, indésirables, brouillons et envoyés ; `folder` : un dossier d'une seule boîte), `folder`, `state` (`all`, `todo`, `done`), `labelIds` (au moins un de ces libellés), `unread`, `text` (objet, adresses ou corps), `from`, `to`, `subject`, `body` (250 max chacun), `since` / `until` (inclus, fin après début), `attachments`, `projectId` (mails liés au projet, envoyés compris). Portée `folder` sans dossier ou avec plusieurs boîtes : « Choisissez le dossier (d’une seule boîte). ». |
| `mailSearchSchema` / `MailSearchInput`               | Dossier de recherche enregistré dans Ordo : `label` (requis, 250) et critères.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `EMPTY_MAIL_SEARCH`                                  | Critères d'une nouvelle recherche : toutes les boîtes, boîtes de réception, tous états.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |

Internes : `hostSchema`, `portSchema`, et les longueurs des champs à format (`SERVER_FIELD_MAX` 255, `SERVER_PASSWORD_MAX` 1 000, `SIGNATURE_MAX` 100 000, `FOLDER_PATH_MAX` 500, `ID_MAX` 100).
